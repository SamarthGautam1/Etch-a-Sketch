# Etch-a-Sketch 🎨

An interactive browser-based drawing grid built with HTML, CSS (Flexbox), and JavaScript.

This project is part of The Odin Project's Foundations course. The goal is to create a dynamic sketchpad that allows the user to draw by hovering over grid squares and to regenerate the grid at different sizes.

---

## 🚀 Features

- 🖱️ Hover over squares to "draw"
- 🧮 Default 16×16 grid
- 🔢 Custom grid sizes (up to 100×100) via prompt
- 🧽 Grid resets and resizes dynamically
- 📏 Responsive square sizing with `flex-wrap` and `calc()`

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox)  
- Vanilla JavaScript (DOM manipulation)

---

## 💻 How to Use

1) Clone the repository by running these commands in bash:-
   git clone https://github.com/SamarthGautam1/Etch-a-Sketch.git
   cd Etch-A-Sketch

2) Open index.html in your browser.

3) Click the "Generate new grid?" button to set a custom grid size (max 100).

4) Hover your mouse over the grid to start sketching!
